# loci serve-http API 实测记录（2026-09-19）

环境：loci v0.5.0 @ `E:\work\gitee\loci`，Windows，索引含 minimax-h3-turing 文档 210
chunks + 1 条测试记忆。启动方式（CLI bug 期间的替代）：

```sh
python -c "from loci.http_api import run_server; from loci import config; run_server(config.load(), '127.0.0.1', 8765)"
```

配置：loci `config.toml` 追加 `[http] token = "…"`（不写则每次启动随机 token 且只打印
前 8 位，无法稳定连接）。

```sh

curl http://127.0.0.1:8765/health
# {"error": "unauthorized"}   ← 所有路径都要求 Bearer
```

## POST /search

请求 `{"query":"T8","k":3}`：

```json
{"result": "[1] E:\\work\\gitee\\minimax-h3-turing\\docs\\09-pdd-backport.md > 09 · PDD 提前落地：不等 release 的 master backport 实录 > 数据与机理\n## 数据与机理\n\n- 8 步给 T8 的命中窗口是 6/8…\n\n[2] E:\\work\\gitee\\loci\\wiki\\在-2080ti-上跑-h3-的加速路线有哪些.md > 在 2080Ti 上跑 H3 的加速路线 > 可用加速路线\n## 可用加速路线\n\n[3] …"}
```

要点：

- 头部格式 `[N] <path> > <section chain>`；section 本身可含 ` > `（嵌套标题链），只能按
  第一个 ` > ` 切分
- 块内文本含 `\n\n`（markdown 段落），**不能**按空行分块——按行首 `[N] ` 正则切块
- 正文截断到 500 字符（loci 侧行为）
- `tag:"memory"` 整词匹配 frontmatter tags；`in` 是路径子串
- 无结果：`{"result": "(no results)"}`
- **空查询 `{}`：连接直接中断**（handler 异常，无响应）——插件端必须拦
- BM25-only 命中时 distance 为 null（本次未在 HTTP 层观察到分数，分数不出 HTTP）

## POST /ask

请求 `{"question":"T8 BlockCache 的默认比例是多少？"}`，实测 **20.9s**（glm-4.6）：

```json
{"result": "T8 BlockCache 的默认参数（阈值）是 0.12。\n\n[source: E:\\work\\gitee\\loci\\wiki\\在-2080ti-上跑-h3-的加速路线有哪些.md > 可用加速路线 > T8 BlockCache]\n[source: E:\\work\\gitee\\minimax-h3-turing\\docs\\08-t8-blockcache-4step.md > 数据]"}
```

要点：引用行 `[source: path > section]` 连续排在尾部，逐行一条。

## POST /remember

请求 `{"text":"…","title":"loci-dsh 架构决策","tags":["decision","loci-dsh"]}`：

```json
{"result": "remembered: E:\\work\\gitee\\loci\\memories\\20260919-144939-loci-dsh-架构决策.md (1 chunks, searchable now)"}
```

要点：

- 文件名 = `YYYYMMDD-HHMMSS-<slug(title)[:48]>.md`（时间流的天然排序键）
- 写入即时入索引，马上能被 `/search {"tag":"memory"}` 查到
- `tags` 在 HTTP 是 **JSON 数组**（CLI 是逗号分隔字符串）
- 自动追加 `memory` 标签

## 踩坑记录

1. **Git Bash 发中文 JSON 会按 GBK 编码** → loci `json.loads` 直接
   UnicodeDecodeError。测试时用 `--data-binary @file.json`，文件由 Python 以 UTF-8 写。
2. loci 响应头 `Content-Type: application/json` 无 charset，body 为 UTF-8。
3. 无任何 CORS 头、无 OPTIONS 处理——浏览器直连必被拦（插件用 host 侧代理绕开）。
