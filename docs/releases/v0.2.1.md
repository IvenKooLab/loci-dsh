## Changelog

UX polish release: the Status view now ends with a one-line footer — version plus a **Star on GitHub** invite.

Why: most installs happen via `dsh plugin add github:...`, which clones straight from git and never touches the repo page. The sidebar itself is the only surface every user is guaranteed to see.

No API changes. Update in place:

```sh
dsh plugin --profile web add github:IvenKooLab/loci-dsh
```
