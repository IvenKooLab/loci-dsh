## Changelog

First public release of **loci-dsh** — put the [loci](https://github.com/IvenKooLab/loci) second brain into the [DeepSeek Harness (dsh)](https://github.com/deepseek-ai/deepseek-harness) web sidebar.

A 🧠 **loci memory** tab (via dsh-better-sidebar) with four views:

- **Search** — hybrid retrieval with memories-only and path filters
- **Ask** — LLM answers with citation chips, optional claim-by-claim verification
- **Memories** — day-grouped memory browsing + quick capture (title / text / tags)
- **Status** — connection state, store summary, per-source chunk stats

Pure UI layer: the host half proxies `loci serve-http` same-origin (no CORS, no core fork).

### Install

```sh
dsh plugin --profile web add dsh-better-sidebar
dsh plugin --profile web add github:IvenKooLab/loci-dsh     # or: loci-dsh (npm, later)
```

Or attach the tarball manually: `dsh plugin --profile web add loci-dsh-0.1.1.tgz`

### Requirements

Node.js >= 24 · dsh 0.1.5+ · dsh-better-sidebar · loci >= 0.6.2 (`loci serve-http`, fixed `[http] token` in config.toml)

Setup details: [README](https://github.com/IvenKooLab/loci-dsh#install) · [中文文档](https://github.com/IvenKooLab/loci-dsh/blob/main/README.zh-CN.md)

## 更新日志

**loci-dsh** 首个公开版本——把 [loci](https://github.com/IvenKooLab/loci) 第二大脑装进 [DeepSeek Harness (dsh)](https://github.com/deepseek-ai/deepseek-harness) 的 Web 侧边栏。

通过 dsh-better-sidebar 提供一个 🧠 **loci 记忆** 标签页，含四个视图：

- **搜索**——混合检索，支持仅记忆库、按路径过滤
- **问答**——LLM 回答带引用芯片，可选逐条核验
- **记忆**——按日分组的记忆浏览 + 快速速记（标题 / 正文 / 标签）
- **状态**——连接状态、库存概要、各来源分块统计

纯 UI 层：host 半侧同源代理 `loci serve-http`（无 CORS、不改 loci 核心）。

### 安装

```sh
dsh plugin --profile web add dsh-better-sidebar
dsh plugin --profile web add github:IvenKooLab/loci-dsh     # 或：loci-dsh（npm，后续）
```

也可以手动挂载 tarball：`dsh plugin --profile web add loci-dsh-0.1.1.tgz`

### 环境要求

Node.js ≥ 24 · dsh 0.1.5+ · dsh-better-sidebar · loci ≥ 0.6.2（`loci serve-http`，config.toml 中固定 `[http] token`）

详细配置见 [README](https://github.com/IvenKooLab/loci-dsh#install) 与 [中文文档](https://github.com/IvenKooLab/loci-dsh/blob/main/README.zh-CN.md)。
