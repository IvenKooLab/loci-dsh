## Changelog

🕸 **Graph view**: browse [loci](https://github.com/IvenKooLab/loci)'s knowledge graph (loci >= 0.6.0, `loci graph build`) as a fifth sidebar view.

- Entity chips with degree badges and SPO relation rows (`subject predicate object`)
- Click any entity (chip or term) to filter its relations; click again to clear
- An entity search box for larger graphs

Enable it with one config row:

```yaml
- id: loci-dsh
  config:
    graphPath: 'C:/path/to/loci/chroma_db/graph.json'   # default <store>/graph.json
```

The host half reads `graph.json` directly from disk (mtime-cached) — no new loci endpoints needed. Without the setting the view renders a setup hint.

## 更新日志

🕸 **图谱视图**：新增第五个侧栏视图，浏览 [loci](https://github.com/IvenKooLab/loci) 的知识图谱（需 loci ≥ 0.6.0，`loci graph build`）。

- 实体芯片带度数徽章，SPO 关系行（`主语 谓词 宾语`）
- 点击任意实体（芯片或正文词）筛选其关系，再点一次取消
- 大图谱可用实体搜索框

一行配置即可开启：

```yaml
- id: loci-dsh
  config:
    graphPath: 'C:/path/to/loci/chroma_db/graph.json'   # 默认 <store>/graph.json
```

host 半侧直读磁盘上的 `graph.json`（按 mtime 缓存），不需要 loci 新增端点。未配置时该视图显示设置提示。
