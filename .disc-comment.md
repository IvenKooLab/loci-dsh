Update shipped: **v0.2.0 adds a 🕸 Graph view** — browse [loci](https://github.com/IvenKooLab/loci)'s knowledge graph right in the sidebar.

![graph](https://raw.githubusercontent.com/IvenKooLab/loci-dsh/main/docs/screenshots/graph.png)

- Entity chips with degree badges, SPO relation rows (`subject predicate object`)
- Click any entity to filter its relations, click again to clear
- Powered by `loci graph build` (loci ≥ 0.6.0): one config row (`graphPath`) and the host half reads `graph.json` directly, mtime-cached — no new loci endpoints needed

Also new since the first post: **featured in [awesome-deepseek-harness](https://github.com/0xsline/awesome-deepseek-harness)** (Memory & Knowledge section).

Install/update:

```sh
dsh plugin --profile web add github:IvenKooLab/loci-dsh
```
